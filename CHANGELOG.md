## [v0.3.0] - 2026-06-20

### Highlights

- Redis KVS backend for production caching and state management
- Session storage with backend-agnostic server-side session management

### Added

- Redis KVS backend re-export from omnistorage-core ([`d363ef1`](https://github.com/plexusone/omnistorage/commit/d363ef1))
- Session storage interface re-export with `session.Store`, `session.Session` ([`6ab24bb`](https://github.com/plexusone/omnistorage/commit/6ab24bb))
- In-memory session backend at `session/backend/memory` ([`6ab24bb`](https://github.com/plexusone/omnistorage/commit/6ab24bb))
- KVS-backed session backend at `session/backend/kvs` ([`6ab24bb`](https://github.com/plexusone/omnistorage/commit/6ab24bb))

## [v0.2.0] - 2026-05-03

- All 9 storage backends now included: 5 core + 4 cloud
- Key-value storage (kvs) interfaces re-exported

### Added

- Core backends auto-registered: channel, dropbox, file, memory, sftp ([`c851a2f`](https://github.com/plexusone/omnistorage/commit/c851a2f))
- KVS interface re-exports: Store, ListableStore, DocumentStore ([`d614f9b`](https://github.com/plexusone/omnistorage/commit/d614f9b))
- KVS backend wrappers: `kvs/memory` and `kvs/sqlite` ([`d614f9b`](https://github.com/plexusone/omnistorage/commit/d614f9b))

### Dependencies
