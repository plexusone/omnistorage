# OmniStorage v0.2.0

*Released: May 3, 2026*

## Highlights

- All 9 storage backends now included: 5 core + 4 cloud
- Key-value storage (kvs) interfaces re-exported

## Overview

This release expands OmniStorage to include all core backends from omnistorage-core, bringing the total to 9 backends. Additionally, key-value storage (KVS) interfaces are now re-exported for caching, state management, and structured data use cases.

## Added

### Core Backends

The following backends from omnistorage-core are now auto-registered:

| Backend | Registry Name | Description |
|---------|---------------|-------------|
| File | `file` | Local filesystem storage |
| Memory | `memory` | In-memory storage (testing) |
| Channel | `channel` | Go channel-based IPC |
| SFTP | `sftp` | SSH file transfer |
| Dropbox | `dropbox` | Dropbox cloud storage |

### KVS Interfaces

KVS interface re-exports for flexible key-value storage:

- `kvs.Store` - Basic key-value operations
- `kvs.ListableStore` - Key enumeration support
- `kvs.DocumentStore` - Document-oriented storage

### KVS Backends

- `kvs/memory` - In-memory KVS backend
- `kvs/sqlite` - SQLite-backed KVS backend

## Dependencies

- Update `github.com/plexusone/omnistorage-core` from v0.3.0 to v0.4.0

## Usage

### SQLite KVS

```go
import "github.com/plexusone/omnistorage/kvs/sqlite"

store, _ := sqlite.New(sqlite.Config{Path: "data.db"})
store.Set(ctx, "user:123", userData, 24*time.Hour)
```

### In-Memory KVS

```go
import "github.com/plexusone/omnistorage/kvs/memory"

store := memory.New()
store.Set(ctx, "temp:key", data, 5*time.Minute)
```
