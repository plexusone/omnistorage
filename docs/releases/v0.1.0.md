# OmniStorage v0.1.0

*Released: April 25, 2026*

## Highlights

- Initial release of OmniStorage aggregator package
- Auto-registers all provider backends for unified storage access

## Overview

OmniStorage is a unified storage abstraction layer for Go. This aggregator package re-exports the core interfaces from [omnistorage-core](https://github.com/plexusone/omnistorage-core) and imports all provider backends for automatic registration.

## Added

- Aggregator package re-exporting core interfaces from omnistorage-core
- Auto-registration of S3 backend from omni-aws
- Auto-registration of GitHub Releases backend from omni-github
- Auto-registration of GCS and Google Drive backends from omni-google

## Documentation

- README with quick start and backend reference

## Dependencies

- `github.com/plexusone/omnistorage-core` v0.3.0

## Quick Start

```go
import (
    "github.com/plexusone/omnistorage"
)

// All backends are automatically registered via init()
backend, err := omnistorage.Open("s3", map[string]string{
    "bucket": "my-bucket",
    "region": "us-east-1",
})
```

## Included Backends

| Backend | Registry Name | Description |
|---------|---------------|-------------|
| Amazon S3 | `s3` | AWS S3 storage |
| GitHub Releases | `github` | GitHub Releases backend |
| Google Cloud Storage | `gcs` | GCS backend |
| Google Drive | `drive` | Google Drive backend |
